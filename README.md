# Intersmart

A responsive frontend implementation based on the provided Figma design.

## Tech Stack

* Next.js
* React
* JavaScript
* Tailwind CSS

## Getting Started

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the project.

## Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
